# Plan,t — 공간 기반 플랜테리어 추천·배치 웹앱

내 공간을 등록하면 조건(채광·반려동물·관리 난이도·배치 위치)에 맞는 식물을 추천하고,
공간 사진 위에 식물을 배치(누끼 합성·톤/그림자 맞춤)해 시안을 만들 수 있는 단일 파일 웹앱입니다.

- **바로 보기:** https://kimye2121.github.io/planty-app/
- 단일 `index.html` (식물 사진·누끼·샘플 모두 내장). 정적 호스팅에 파일 하나만 올리면 동작합니다.
- 외부 의존: Tailwind·Iconify·Google Fonts CDN, 내 사진 배경제거(@imgly).
